# Changes 2026-09-24 - folder reorganisation

Branch `reorganize`, squash-merged into `main` as "Reorganizing data".

## `[CHANGED]` Repo layout

Files are grouped by kind instead of all sitting in the project root:

| Folder | Holds | Git |
|---|---|---|
| `config/` | files the user edits: `avoidable.json`, `nights.json`, `roster.txt`, `consumables.json`, `defensives.json` + the `*.example.json` templates | tracked except `nights.json` and `roster.txt` |
| `data/` | files the tool writes: `cache/` (was `.cache/`), `abilities_seen.json`, `mplus_history.json` | whole folder ignored |
| `dashboards/` | built HTML; now the **default output location** of `build_dashboard.py` (`-o` still overrides) | whole folder ignored (player names) |
| `docs/` | `CHANGES_*.md`, `ROADMAP_*.md`, `reviews/REVIEW_*.md`, `plans/` (was `docs/superpowers/plans/`) | tracked |

`CLAUDE.md`, `README.md`, the Python modules, `dash/`, `tests/`, `systemd/`, `legacy/` stay where they were.

## `[ADDED]` `path.py`

Single source of truth for the layout: `ROOT`, `CONFIG_DIR`, `DATA_DIR`, `DASHBOARD_DIR`. Creates `data/` and `dashboards/`
on import because both are git-ignored and therefore missing in a fresh clone.

`[DECISION]` Named `path.py` (not `paths.py`); import names explicitly (`from path import DATA_DIR`) - `build_dashboard.py`
has a local variable called `path`, so a bare `import path` there would be shadowed.

## `[CHANGED]` Modules now import their locations from `path.py`

- `cache.py`: `CACHE_DIR = data/cache`
- `collect_data.py`: `NIGHTS_FILE`, `CONSUMABLES_FILE`, `DEFENSIVES_FILE` -> `config/` (`HERE` kept; still used internally)
- `mplus.py`: `ROSTER_FILE` -> `config/`, `HISTORY_FILE` -> `data/`; `HERE` removed
- `dash/common.py`: `AVOIDABLE_FILE` -> `config/`, `MPLUS_FILE` -> `data/`; `HERE` removed
- `build_dashboard.py`: `abilities_seen.json` -> `data/`; default output -> `dashboards/`; no longer imports `HERE`
- `systemd/wcl-dashboard.sh`: `OUT=dashboards/...` (the script already `cd`s to the project root)

## `[CHANGED]` `.gitignore`

Folder rules (`data/`, `dashboards/`) replace the per-file list (`.cache/`, `dashboard_*.html`, `serenity-*.html`, `out/`,
`abilities_seen.json`, `mplus_history.json`). Per-guild config is ignored by path under `config/`.
`[DECISION]` Only `nights.json` (report codes) and `roster.txt` (player names) are ignored. `avoidable.json`,
`consumables.json` and `defensives.json` are tracked - they hold ability names, not guild or player data.
