# Dashboard Redesign (replicate `serenity-dashboard-rebuilt.html`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the full-dataset dashboard produced by `build_dashboard.py` the visual system, markup patterns and progression chart of the hand-built example `serenity-dashboard-rebuilt.html`, without losing any existing tab, filter or section.

**Architecture:** One token file (`dash/static/tokens.css`) is the single source of colour, type and spacing values; Python reads it for Plotly figures and inline colours, JS reads it through `getComputedStyle`, CSS uses the variables directly. Markup patterns from the example (KPI `<dl>` tiles, progress cards, insight articles, `.scroller` tables with visible captions and `<th><button>` sorting, `<figure class='chart'>` wrappers) are implemented once as helpers in `dash/common.py` (Python) and `dash/static/dash.js` (browser) and every renderer calls those helpers. The boss-tab hero chart (boss HP per pull) becomes the example's inline SVG chart; every other chart stays Plotly but is restyled from the tokens and wrapped in the same `<figure>`.

**Tech Stack:** Python 3.12+ (user runs 3.14, venv at `venv/`), Plotly (CDN, unchanged), vanilla JS (one IIFE in `dash/static/dash.js`), CSS custom properties, pytest + quickjs (JS syntax), headless Firefox for screenshots.

**Spec:** `serenity-dashboard-rebuilt.html` (project root) is the design reference: its `<style>` block is the visual spec, its Overview panel is the Home spec, its `data-ulatek` payload + `drawChart()` is the boss-tab spec. `CLAUDE.md` §7 and §10 are the functional spec that must survive.

- **Existing DOM contracts the JS and tests depend on** (keep verbatim): `class='pull-grid' data-tab='tabN'`, `id='detail_tabN'`, `<button type='button' class='pull-box`, `role='tab'` only in Python markup, `data-diff='<Difficulty>'` on boss tab buttons, `id='tabSelect'`, `.tab-btn .badge` element, `id='static_tabPlayers'`, `#jsError`, `#oldBrowser`, `id='tab_names'`, `<section id='tabN' class='tab-panel'>`.

- [ ] **Step 4: Add `load_tokens()` to `dash/common.py`**

After the `MPLUS_FILE` line (line 14) add:
```python
import re

TOKENS_FILE = os.path.join(os.path.dirname(os.path.abspath(__file__)), "static", "tokens.css")
REQUIRED_TOKENS = frozenset({
    "surface-page", "surface-card", "surface-raised", "border", "border-strong", "ink", "ink-dim",
    "accent", "on-accent", "good", "warn", "bad",
    "series-1", "series-1-rgb", "series-2", "series-3", "series-4", "series-5", "series-6",
    "font", "font-num",
})


def load_tokens() -> dict[str, str]:
    """Design values from tokens.css: {'accent': '#c9a227', ...}. The CSS file is the only source of truth."""
    with open(TOKENS_FILE, encoding="utf-8") as f:
        text = f.read()
    toks = {name: value.strip() for name, value in re.findall(r"--([a-z0-9-]+)\s*:\s*([^;]+);", text)}
    missing = sorted(REQUIRED_TOKENS - toks.keys())
    if missing:
        raise ValueError(f"tokens.css is missing: {', '.join(missing)}")
    return toks
```

```python
def table(headers: list[tuple[str, str]], rows_html: str, extra_class: str = "", caption: str = "") -> str:
    """
    headers: (label, type) with type 'num' (right-aligned, numeric sort), 'str' (text sort) or 'none' (not sortable).
    Sortable headers hold a <button> so keyboard users get a real control; numeric cells should carry class='right'.
    """
    ths = ""
    for h, t in headers:
        cls_attr = " class='right'" if t == "num" else ""
        if t == "none":
            ths += f"<th scope='col' data-type='none'{cls_attr}>{esc(h)}</th>"
        else:
            ths += f"<th scope='col' data-type='{t}'{cls_attr}><button type='button' aria-label='Sort by {esc(h)}'>{esc(h)}</button></th>"
    cap = f"<caption>{esc(caption)}</caption>" if caption else ""
    return f"<div class='scroller'><table class='sortable {extra_class}'>{cap}<thead><tr>{ths}</tr></thead><tbody>{rows_html}</tbody></table></div>"
```

```python
def fig_html(fig: go.Figure, height: int = 380, div_id: str | None = None) -> str:
    """Plotly figure in the example's card <figure>; the Plotly title moves into the <h3>."""
    title = ""
    if fig.layout.title and fig.layout.title.text:
        title = str(fig.layout.title.text)
    fig.update_layout(title=None, paper_bgcolor=CHART_BG, plot_bgcolor=CHART_BG, height=height, colorway=SERIES,
                      font=dict(color=TOKENS["ink"], family=TOKENS["font"]),
                      xaxis=dict(gridcolor=TOKENS["border"], zerolinecolor=TOKENS["border"]),
                      yaxis=dict(gridcolor=TOKENS["border"], zerolinecolor=TOKENS["border"]),
                      legend=dict(font=dict(color=TOKENS["ink-dim"])))
    if not getattr(fig.layout.margin, "t", None):
        fig.update_layout(margin=dict(l=40, r=20, t=20, b=40))
    kwargs = dict(full_html=False, include_plotlyjs=False, config={"responsive": True, "displaylogo": False})
    if div_id:
        kwargs["div_id"] = div_id
    try:
        body = fig.to_html(**kwargs)
    except TypeError:  # very old plotly without div_id
        kwargs.pop("div_id", None)
        body = fig.to_html(**kwargs)
    head = f"<div class='chart-head'><h3>{esc(title)}</h3></div>" if title else ""
    return f"<figure class='chart'>{head}<div class='plot'>{body}</div></figure>"
```
